# BrandGrow Theatre Ads — Full Responsive Project

Ready-to-deploy static website.

## Features
- Responsive desktop/tablet/mobile layout
- Readable typography at different screen widths
- Mobile navigation
- Mobile floating Call Now button
- `tel:+917601044533` call action
- WhatsApp, email and Instagram icon buttons
- Smooth scroll and reveal animations
- Reduced-motion accessibility
- BrandGrow theatre advertising campaign artwork
- No build step

## Run in VS Code
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Install **Live Server** by Ritwick Dey.
4. Open `index.html`.
5. Right-click → **Open with Live Server**.
